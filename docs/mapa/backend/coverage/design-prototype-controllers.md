# Design and Prototype Controllers / Controllers de Design e Protótipos

| File | Responsibility |
|---|---|
| `ui/server/controllers/design.controller.js` | Reads, detects and saves project design profiles. / Lê, detecta e salva perfis de design do projeto. |
| `ui/server/controllers/inspect-edit.controller.js` | Previews an assisted edit to an inspected project element. / Gera preview de edição assistida de elemento inspecionado do projeto. |
| `ui/server/controllers/prototype-components.controller.js` | Lists prototype components and serves registry component source. / Lista componentes do protótipo e fornece fonte do registro. |
| `ui/server/controllers/prototype.controller.js` | Lists, creates and imports project prototypes and artifacts. / Lista, cria e importa protótipos e artefatos do projeto. |
