# Atelier Controllers / Controllers do Atelier

| File | Responsibility |
|---|---|
| `ui/server/controllers/atelier-agent-run.controller.js` | Starts or resumes prototype agent loops and streams events over SSE. / Inicia ou retoma loops de agente do protótipo e transmite eventos por SSE. |
| `ui/server/controllers/atelier-scratchpad.controller.js` | Lists, reads and cleans temporary prototype scratchpad files. / Lista, lê e limpa arquivos temporários de rascunho do protótipo. |
