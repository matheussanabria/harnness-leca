# Virtual Office UI / Interface do Escritório Virtual

| File | Responsibility |
|---|---|
| `ui/public/js/office-audio.js` | Generates and toggles retro sound effects through Web Audio. / Gera e alterna efeitos sonoros retrô pela Web Audio API. |
| `ui/public/js/office-avatar.js` | Defines the articulated Three.js developer avatar. / Define o avatar articulado de desenvolvedor em Three.js. |
| `ui/public/js/office-orchestration-panel.js` | Renders the orchestration center drawer and selected graph entity panels. / Renderiza a gaveta do centro de orquestração e painéis da entidade selecionada. |
| `ui/public/js/office-state.js` | Owns shared virtual office state and observability stream. / Mantém estado compartilhado do escritório virtual e stream de observabilidade. |
