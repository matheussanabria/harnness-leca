# Map CLI

| File | Responsibility |
|---|---|
| `tools/mapa.js` | Map CLI: `find` names the map file for a path or keywords, `check [--strict]` validates the tree, `build [--write]` regenerates the index. |
| `tools/lib/mapa/frontmatter.js` | Parser and schema for map frontmatter (domain, module, feature, summary, paths, keywords, updated). |
| `tools/lib/mapa/glob.js` | Minimal glob matcher for `paths` (`**`, `*`, `?`, plain folders). |
| `tools/lib/mapa/scan.js` | Reads `docs/mapa/**` with sizes and frontmatter, and lists tracked source files the map must cover. |
| `tools/lib/mapa/check.js` | Map rules: size caps, folder/frontmatter match, dead paths, orphans; legacy files only warn. |
| `tools/lib/mapa/query.js` | `findMapa` (by path or keyword) and `buildIndex` (generated index table). |
| `tests/mapa-tooling.test.js` | Frontmatter, glob, check, find and build behavior. |
| `MAPA.md` | Map entry point and index (generated by `build --write`); area detail lives in `docs/mapa/`. |
| `docs/mapa/*.md` | Legacy per-area map files, each under about 20 KB, being migrated to the domain/module tree. |
| `scripts/lib/read-mapa.js` | Reads the whole map for the pre-commit hook and the tests. |
