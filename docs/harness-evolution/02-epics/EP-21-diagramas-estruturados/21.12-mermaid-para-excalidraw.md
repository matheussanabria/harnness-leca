# EP-21.12: Mermaid para Excalidraw, como ação explícita

## Objetivo
Levar um diagrama para o quadro livre para anotar à mão, sem perder o original.

## Requisitos
- Botão "Abrir como quadro" na ilha `canvas-diagram`, ativo só para flowchart, sequência e classes (limite do `@excalidraw/mermaid-to-excalidraw`).
- Cria um board `board` novo com a cena convertida, com `links` apontando para o diagrama de origem; o diagrama não muda.
- Reaproveita a conversão de `canvas-board/applyMermaid.ts`; se for preciso, mover o núcleo para `features/board/`.

## Critérios de aceite
- Navegador: converter um flowchart, abrir o quadro novo, conferir que o diagrama de origem segue igual.
