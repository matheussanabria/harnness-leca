# EP-21.10: Chat do Flow

## Objetivo
O chat gera e altera fluxos com `<flow mode="replace|merge">` contendo JSON só com a parte semântica (`nodes`, `edges`); o layout vem do ELK.

## Requisitos
- Formato pedido ao modelo é compacto: `{"nodes":[{"id","type","label"}],"edges":[["a","b","rótulo?"]]}`; o normalizador converte para `flow@1`.
- `merge` atualiza por id: nós novos entram, existentes mudam rótulo/tipo, nada é apagado sem `"remove":[ids]` explícito.
- Validação com `validate.ts` da 21.07; falha gera um reparo automático com a lista de erros, como na 21.05.
- Estado enviado ao prompt: só `graph` resumido (ids, tipos, rótulos, arestas), nunca posições.
- Cenários de Flow na sonda (linear, com decisão, executável com ciclo proibido, grande, `merge`), com o modelo escolhido na 21.06 como ponto de partida.

## Critérios de aceite
- Testes do normalizador e do `merge`; navegador: gerar um pipeline de agentes, pedir um passo extra, ver o layout aplicado.
- Relatório da sonda para Flow anexado ao da 21.06.
