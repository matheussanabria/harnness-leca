# EP-21.07: Modelo puro do Flow

## Objetivo
Grafo `flow@1` imutável e testável sem React, no molde de `features/mindmap` (modelo, comandos, histórico).

## Requisitos
- `types.ts`: `FlowData` com `graph` e `layout` separados (ADR-014).
- `nodeTypes.ts`: catálogo de tipos de nó como dados (`start`, `end`, `step`, `decision`, `agent`, `tool`, `note`), com portas e cor; novos tipos sem código de UI.
- `validate.ts`: ids únicos, arestas para nós existentes, portas válidas, ciclo (`purpose: "executable"` proíbe ciclos; `doc` permite), limites (500 nós, 2000 arestas).
- `commands.ts` e `history.ts`: adicionar, ligar, mover, renomear, apagar com arestas pendentes, agrupar; desfazer e refazer.
- `adapt.ts`: conversão `flow@1` para nós e arestas do React Flow e de volta, sem perder `params`.

## Critérios de aceite
- Testes de validação (inclui ciclo e aresta solta), de comandos e de ida e volta do adaptador.
- Nenhum import de `@xyflow/react` em `features/flow`.
