# EP-21.09: Layout automático com ELK.js

## Objetivo
Organizar o fluxo com um clique e posicionar fluxos gerados por IA, que chegam sem coordenadas.

## Requisitos
- `elkjs` em versão exata, carregado sob demanda; em Web Worker se o tempo passar de 100 ms em 200 nós.
- Direções: esquerda para direita e cima para baixo; algoritmo `layered`; espaçamentos fixos.
- `layout.ts` puro: recebe `graph` e tamanhos dos nós, devolve `layout.positions`; não toca em `graph`.
- Aplicar o layout é um passo único de desfazer.

## Critérios de aceite
- Teste: posições para todos os nós, nenhuma sobreposição em um DAG de 50 nós, `graph` inalterado.
- Medição registrada do chunk e do tempo para 200 nós.
