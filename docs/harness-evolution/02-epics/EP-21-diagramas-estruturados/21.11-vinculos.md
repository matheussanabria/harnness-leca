# EP-21.11: Vínculos

## Objetivo
Ligar qualquer board (todos os kinds) a histórias, épicos, agentes e projetos, para planejar, documentar e auditar a partir do diagrama.

## Requisitos
- Campo `links` na raiz do board (ADR-014): validação de tipo e id, máximo 20, deduplicação.
- `GET /api/canvas/boards?link=story:EP-21.04` para achar os diagramas de uma história.
- UI: chips de vínculo no cabeçalho de cada ilha e no catálogo lateral; ligação com o Scrum (EP-18) só por id, sem acoplamento de código.
- Avaliar com EP-17.08 (metadados no SQLite) para não indexar duas vezes.

## Critérios de aceite
- Testes de validação e filtro; boards antigos sem `links` seguem válidos.
