# EP-21.03: Modelo puro do diagrama Mermaid

## Objetivo
Toda a lógica que não depende de React, testável em `node:test`, como em `features/board`.

## Requisitos
- `types.ts`: `DiagramData`, `DiagramType` (flowchart, sequence, class, state, er, gantt, mindmap-mermaid recusado).
- `detect.ts`: tipo pelo cabeçalho (ignora `%%` e front matter `---`), lista de tipos suportados.
- `validate.ts`: wrapper lazy de `mermaid.parse` que devolve `{ ok, line?, message }` curto e legível para humanos e para o reparo pelo modelo.
- `render.ts`: `initialize` com a config segura do ADR-014; render para SVG sanitizado; id único por render.
- `api.ts`: cliente tipado (reaproveitar o padrão de `features/board/api.ts`; se duplicar, extrair `features/canvas/apiBase.ts`).
- `exportName.ts` / export: SVG, PNG (via canvas), `.mmd` e bloco Markdown com cerca `mermaid`.

## Critérios de aceite
- Testes cobrem detecção, mensagem de erro com linha, limite de 64 KB e nomes de export.
- Nenhum import de `mermaid` fora de `validate.ts` e `render.ts`.

## Evidências
- Branch `feat/ep-21.03-diagram-model` (2026-11-22). Dossiê: `docs/features/diagram-model/` (BDD CP-01 a CP-08, todos automatizados).
- Mermaid 11.17.2 e DOMPurify 3.4.17 reais testados no Chrome (`tests/diagram-browser.test.js`): os 6 tipos aceitos, mindmap e pie recusados, 11 casos de linha, SVG sem nada executável, PNG real.
- Achado: `mermaid.parse` não roda em Node puro (`DOMPurify.addHook is not a function`), então a validação só é testável com DOM; o resto do modelo é puro e roda em `node:test`.
- Achado: o Mermaid conta a linha do erro depois de remover front matter, comentários, diretivas e as linhas em branco antes deles. `lineMap.ts` converte de volta para a linha digitada. Caso aproximado conhecido: um `%%` no fim de uma linha de código junta a linha seguinte; a mensagem aponta a linha do comentário e cita o trecho.
- Extração pedida pela história: `features/canvas/apiBase.ts` (erro, `failure`, `createCanvasHttp`), usada por `board/api.ts` e `diagram/api.ts`; os 49 testes do board continuam passando e a interface pública não mudou. O cliente do mindmap tem outro formato e não foi tocado.
- Fora desta história: nenhuma tela (a ilha do editor é a 21.04).
