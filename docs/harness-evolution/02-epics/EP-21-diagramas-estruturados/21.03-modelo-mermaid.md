# EP-21.03: Modelo puro do diagrama Mermaid

## Objetivo
Toda a lógica que não depende de React, testável em `node:test`, como em `features/board`.

## Requisitos
- `types.ts`: `DiagramData`, `DiagramType` (flowchart, sequence, class, state, er, gantt, mindmap-mermaid recusado).
- `detect.ts`: tipo pelo cabeçalho (ignora `%%` e front matter `---`), lista de tipos suportados.
- `validate.ts`: wrapper lazy de `mermaid.parse` que devolve `{ ok, line?, message }` curto e legível para humanos e para o reparo pelo modelo.
- `render.ts`: `initialize` com a config segura do ADR-014; render para SVG sanitizado; id único por render.
- `api.ts`: cliente tipado (reaproveitar o padrão de `features/board/api.ts`; se duplicar, extrair `features/canvas/apiBase.ts`).
- `exportName.ts` / export: SVG, PNG (via canvas), `.mmd` e bloco Markdown com cerca `mermaid`.

## Critérios de aceite
- Testes cobrem detecção, mensagem de erro com linha, limite de 64 KB e nomes de export.
- Nenhum import de `mermaid` fora de `validate.ts` e `render.ts`.
