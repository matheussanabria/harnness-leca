# 02.02: Modelo separado de mensagens, sessões e execuções

## 1. Identificação
- **Épico:** [EP-02](README.md)
- **Prioridade:** P0
- **Dependências:** 02.01
- **Bloqueia:** 02.03, 02.04, 02.05, 02.06, 02.07, 02.08

## 2. Contexto
Anteriormente, cada apresentação de chat (modal principal, lateral do Studio e gaveta 3D) misturava arrays ad-hoc de mensagens com manipulação de DOM, complicando a persistência, o isolamento de sessões CLI e o streaming concorrente entre diferentes janelas.

## 3. Objetivo
Definir contratos de tipagem estritos e funções puras de criação e validação para:
- `ChatMessage`: entidade imutável de mensagem com suporte a extração automática de blocos de código acionáveis.
- `ChatSession`: metadados da sessão, contadores e IDs de motor vinculados por projeto.
- `ChatExecutionState`: controle de status (`idle`, `streaming`, `done`, `error`, `cancelled`).

## 4. Requisitos
- RF1: Criar contratos `.d.ts` canônicos (`ui/public/js/types/chat-models.d.ts`).
- RF2: Implementar módulo puro `ui/public/js/modules/chat-models.js` com funções `createChatMessage`, `extractCodeBlocksFromMarkdown`, `createChatSession` e `createChatExecutionState`.
- RF3: Suíte unitária cobrindo normalização, extração de código e instanciação de sessões.

## 5. Critérios de Aceite
- [x] Contratos de tipagem estáticos criados e integrados.
- [x] Extração determinística de blocos de código markdown com metadados de linguagem e caminho de arquivo.
- [x] 100% dos testes unitários passando (`node --test tests/chat-models.test.js`).
