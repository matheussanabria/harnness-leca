# EP-07.04: Previews seguros

## 1. Identificação
- **Épico:** [EP-07](./README.md)
- **Prioridade:** P1
- **Dependências:** [EP-07.03](./07.03-metadados-origem-controle-acesso.md)
- **Bloqueia:** [EP-07.05](./07.05-relacionamentos-mapa-camadas.md) (relacionamentos e Mapa em Camadas)

## 2. Contexto
O inventário da EP-07.03 mostra origem, acesso e estado, mas não permite abrir o artefato. O usuário precisa sair da aba e localizar o arquivo manualmente. Abrir conteúdo de terceiros na própria página também exigiria cuidado: HTML importado não pode executar scripts na origem do harness, e um artefato `local` não pode ser servido para requisições remotas.

## 3. Objetivo
Permitir uma prévia somente leitura do artefato dentro da aba Artefatos, com texto escapado, HTML isolado, imagens e PDF servidos por uma rota controlada. A prévia respeita o acesso registrado e nunca expõe caminho absoluto, manifesto ou conteúdo binário dentro do JSON de metadados.

## 4. Requisitos
**Funcionais**
- RF1: expor `GET /api/project/:slug/artifacts/preview?kind=<tipo>&file=<relativo>` com metadados seguros e, para texto, conteúdo limitado.
- RF2: aceitar `raw=1` somente para HTML, imagem e PDF, servindo os bytes com `Content-Type` correto, `nosniff` e política de sandbox.
- RF3: para `imported`, consultar o manifesto: `local` só é servido em loopback; requisição remota recebe `404` sem revelar a existência.
- RF4: manifesto inválido bloqueia a prévia de importados (falha fechada) em vez de assumir acesso de projeto.
- RF5: restringir cada tipo ao seu diretório e extensões válidas, rejeitando `..`, caminho absoluto, segmento oculto e symlink.
- RF6: limitar texto a 512 KB com indicador de truncamento e binários a 25 MB.
- RF7: HTML é exibido em `iframe` com `sandbox` sem scripts; imagens usam `<img>`; PDF abre pela rota crua; tipos sem prévia mostram aviso.
- RF8: a aba Artefatos ganha botão de visualização e painel de prévia com fechar, título, tipo, tamanho e acesso.
- RF9: o JSON de prévia não devolve conteúdo binário, caminho absoluto, manifesto ou segredo.
- RF10: extrair as rotas de artefatos para `ui/server/routes/artifact.routes.js`, mantendo `router.js` abaixo de 300 linhas.

**Não funcionais**
- Arquivos de até 300 linhas, com resolução de caminho, leitura e HTTP separados.
- Ícones apenas FontAwesome. Nenhum emoji.
- Nenhuma regressão nas abas Scrum, Mapa em Camadas, Quadro, Auditoria e Protótipos.

## 5. Arquitetura
```
GET /api/project/:slug/artifacts/preview?kind&file[&raw=1]
        |
[artifact-preview.controller.js]
        |
[artifact-preview.service.js]
  resolve por tipo -> symlink/travessia -> manifesto (imported)
  -> texto | html | imagem | pdf | sem prévia
        |
[design-artifacts-preview.js]
  texto escapado | iframe sandbox | imagem | link de PDF
```

Contrato JSON:
```json
{
  "ok": true,
  "kind": "imported",
  "file": "artifacts/docs/nota.md",
  "previewKind": "text",
  "mime": "text/markdown",
  "size": 128,
  "access": "project",
  "truncated": false,
  "content": "# Nota",
  "metadata": { "origin": "import", "source": "folder" }
}
```

Para HTML, imagem e PDF, o JSON troca `content` por `url` apontando para `raw=1`. O `iframe` usa `sandbox` vazio, sem scripts. A rota crua responde com `Content-Security-Policy: sandbox; default-src 'none'; style-src 'unsafe-inline'; img-src data:; font-src data:; media-src data:; frame-ancestors 'self'; base-uri 'none'; form-action 'none'`.

## 6. Implementação
1. Criar o serviço de prévia com regras por tipo, resolução segura, acesso e limites.
2. Criar o controller para JSON e `raw=1`, com cabeçalhos restritivos.
3. Extrair as rotas de artefatos de `router.js` e registrar a rota de prévia.
4. Adicionar botão e painel de prévia na aba Artefatos.
5. Cobrir texto, HTML, binário, acesso remoto, manifesto inválido, symlink, controller, rota e limites estruturais.

## 8. Critérios de aceite
- [x] Texto e Markdown aparece escapado, com truncamento explícito.
- [x] HTML é exibido em sandbox sem scripts e sem acesso à origem do harness.
- [x] Imagem e PDF são servidos por `raw=1` com tipo correto e `nosniff`.
- [x] Artefato importado `local` retorna `404` para requisição remota, no JSON e no cru.
- [x] Manifesto inválido bloqueia a prévia de importados.
- [x] Caminho com `..`, absoluto, oculto, symlink ou tipo divergente é rejeitado.
- [x] JSON de prévia não devolve caminho absoluto nem conteúdo binário.
- [x] A aba Artefatos abre e fecha a prévia sem recarregar a página.
- [x] Tipos sem prévia exibem aviso claro.
- [x] `router.js`, serviço, controller, UI, CSS e teste ficam abaixo de 300 linhas e sem emojis.
- [x] `npm test` e `npm run check` verdes.

## 9. Riscos
- **Compatibilidade:** HTML com JavaScript não será interativo na prévia segura; o Ateliê continua sendo o caminho para protótipos interativos.
- **Segurança:** a política bloqueia scripts, formulários, rede e origem; abrir o arquivo cru fora do iframe continua isolado por CSP.
- **Desempenho:** texto para em 512 KB e binário em 25 MB, sem leitura completa de arquivos maiores.
- **Rollback:** remover a rota e o painel desfaz a prévia sem alterar o inventário ou o manifesto.
