# EP-12.11: Criar harness de renderizacao isolada por componente

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.09, 12.10
- **Bloqueia:** 12.12, 12.21

## 2. Contexto
Para garantir que um componente foi extraído com perfeição sem depender de variáveis globais ocultas ou estilos acidentais do host, é fundamental poder renderizá-lo isoladamente em uma sandbox controlada com seus próprios tokens e propriedades de teste.

## 3. Objetivo
Criar o serviço e rota de preview isolado de componente:
- Serviço: `renderComponentPreview(projectDir, componentId, props)`
- Rota: `GET /api/project/:slug/design/registry/:componentId/preview`

## 4. Requisitos
**Funcionais**
- RF1: Montar página HTML limpa carregando `tokens.css`, `theme.css`, o CSS do componente e seu HTML.
- RF2: Injetar script de bootstrap que invoca a função `render<Component>(container, props)` com props default ou passadas na query.
- RF3: Retornar com CSP seguro e cabeçalhos adequados para visualização em iframe sandbox.

**Nao funcionais**
- Leve e sem dependências externas.
- Tempo de resposta inferior a 50ms.

## 5. Implementacao
1. Implementar método no controller de registry para servir o preview HTML.
2. Registrar rota no `ui/server/router.js`.
3. Testar via browser e requisição HTTP.

## 6. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Integracao | Preview de AnnotationList e Accordion responde 200 com HTML montado | `node --test tests/design-preview.test.js` |

## 7. Criterios de aceite
- [x] Rota `/api/project/:slug/design/registry/:componentId/preview` responde com HTML autocontido.
- [x] Renderização exibe o componente funcionalmente ativo.

## 8. Evidencias
- `ui/server/services/design-preview.service.js`: montagem limpa e isolada com resolução dinâmica de dependências, CSS e props de demonstração.
- `ui/server/controllers/design-registry.controller.js` (`apiRegistryPreviewComponent`) e rota registrada em `ui/server/router.js`.
- `tests/design-preview.test.js`: 100% aprovado cobrindo `dis.annotation-list`, `dis.accordion`, `dis.button` e `dis.icon`.
