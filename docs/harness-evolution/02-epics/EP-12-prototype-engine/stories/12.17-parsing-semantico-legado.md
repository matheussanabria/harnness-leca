# EP-12.17: Pipeline de parsing semantico do DOM legado

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.05, 12.13
- **Bloqueia:** 12.18, 12.19, 12.20

## 2. Contexto
No protótipo do DIS (`Main.dc.html`), os componentes estão expressos através de tags proprietárias do DataChef como `<x-import component-from-global-scope="DS.AnnotationList" items="{{notes}}">` e elementos com classes de design system misturados com código imperativo. O importador anterior tratava tudo como texto cego, fazendo o runtime do browser falhar por CSP e destruição do DOM.

## 3. Objetivo
Criar um parser semântico que identifica tags, atributos, bindings (`{{...}}`) e classes de componentes do Design System, mapeando-os para nós semânticos `PrototypeNode` vinculados ao Registry oficial.

## 4. Requisitos
**Funcionais**
- RF1: Parser capaz de reconhecer tags `<x-import component-from-global-scope="DS.XYZ">`.
- RF2: Mapear o identificador global (ex: `DS.AnnotationList`) para o ID canônico do Registry (`dis.annotation-list`).
- RF3: Extrair props estáticas e props interpoladas/bindings (ex: `items="{{notes}}"` gera binding `notes`).
- RF4: Atribuir IDs únicos e estáveis (`node-X`) para cada nó parseado.

**Nao funcionais**
- Arquivo conciso (< 250 linhas), modular e sem dependências pesadas externas.

## 5. Implementacao
1. Criar `ui/server/services/prototype-semantic-parser.service.js`.
2. Implementar regex e analisador léxico de tags semânticas.
3. Testar parsing com trechos reais de `Main.dc.html`.

## 6. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Unitario | Parsear tags x-import, classes DIS e extrair PrototypeNode | `node --test tests/prototype-semantic-parser.test.js` |

## 7. Criterios de aceite
- [x] Parser extrai corretamente tags `<x-import>` com props e bindings.
- [x] Mapeamento canônico para IDs do Registry verificado.

## 8. Evidencias
- `ui/server/services/prototype-semantic-parser.service.js`: analisador de tags `<x-import>`, conversão camelCase, mapeamento canônico de `DS.*` para `dis.*` e extração de bindings `{{stateKey}}`.
- `tests/prototype-semantic-parser.test.js`: 100% dos testes aprovados.
