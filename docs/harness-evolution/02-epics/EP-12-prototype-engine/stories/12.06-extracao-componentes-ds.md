# EP-12.06: Evoluir extracao HTML, CSS e JavaScript

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.05
- **Bloqueia:** 12.07, 12.10, 12.11

## 2. Contexto
Os componentes estao contidos dentro de `dis-design-system.html` em uma secao `<script>` que define funcoes como `AnnotationList`, `Accordion`, etc., alem de centenas de linhas de CSS espalhadas em `<style>`. Precisamos de um extrator capaz de extrair a definicao de um componente, suas dependencias de estilo e emitir o pacote modular do componente.

## 3. Objetivo
Criar o extrator semantico `design-extractor.service.js` e utilizá-lo para extrair o piloto `AnnotationList` (`dis.annotation-list`), gerando seus arquivos limpos em `ds/components/annotation-list/`.

## 4. Requisitos
**Funcionais**
- RF1: Parser capaz de extrair componentes individuais do bundle `@ds-bundle`.
- RF2: Extracao dos blocos de CSS correspondentes as classes do componente.
- RF3: Emissao dos arquivos do componente: `manifest.json`, `annotation-list.html`, `annotation-list.css` e `annotation-list.js`.
- RF4: Declaracao correta das dependencias (ex: `Accordion`, `Fragment`).

**Nao funcionais**
- Arquivo com limite maximo de 250 linhas.
- Preservar os arquivos de origem 100% intactos (leitura exclusiva).

## 5. Arquitetura
- **Servico:** `ui/server/services/design-extractor.service.js`
- **Destino dos artefatos:** `projects/<slug>/design/ds/components/<name>/`

## 6. Implementacao
1. Desenvolver extrator semantico com regex e parsing seguro.
2. Executar extracao do piloto `AnnotationList`.
3. Validar arquivos emitidos.

## 7. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Unitario | Extrair componente com props e classes CSS | `node --test tests/design-extractor.test.js` |

## 8. Criterios de aceite
- [x] Componente `AnnotationList` extraido com manifesto valido.
- [x] Arquivos `.html`, `.css` e `.js` gerados de forma desacoplada e funcional.

## 9. Riscos
- **Compatibilidade:** Classes CSS compartilhadas com seletores complexos.
- **Rollback:** Saida isolada no diretorio `ds/components/`.

## 10. Evidencias
Preenchido em 2026-10-19:
- Extrator implementado: `ui/server/services/design-extractor.service.js` (160 linhas).
- Piloto extraido em: `projects/saude-dispensacao/design/ds/components/annotation-list/` (`manifest.json`, `annotation-list.html`, `annotation-list.css`, `annotation-list.js`).
- Testes unitarios passando: `tests/design-registry.test.js`.
