# História 12.25 — Adaptador de Geração Vanilla HTML/CSS/JS

## Status: Concluída
- **Fase**: F6 — Adaptadores Multiframework (Vanilla, Angular 18 e React 18+)
- **Épico**: EP-12 — Prototype Engine & Design System Multiframework
- **Entrega**: Adaptador gerador de código Vanilla desacoplado (`prototype-codegen-vanilla.service.js`) a partir da árvore semântica do `proto.json` v2, gerando HTML semântico limpo, CSS baseado nos tokens do Design System e ES Modules JavaScript modernos para interações e navegação.

---

## 1. Contexto e Motivação
A árvore semântica do protótipo v2 representa a única fonte de verdade da interface. O adaptador Vanilla é o gerador fundamental de código que transforma a representação declarativa de nós (`PrototypeNode`), slots e bindings em código puramente web padrão, sem dependência de runtimes externos proprietários, pronto para inspeção, exportação e execução rápida em qualquer navegador moderno.

---

## 2. Requisitos e Critérios de Aceite
1. **Geração Estruturada de Componentes e Telas**:
   - `generateVanillaNode(node, registry)`: compila um nó semântico individual para HTML estruturado, mapeando props, classes e slots.
   - `generateVanillaScreen(screen, proto, registry)`: compila uma tela completa com árvore de nós hierárquica.
2. **Integração com Tokens e Estilos**:
   - Gera classes CSS canônicas e vinculação aos tokens de design do projeto (`var(--dis-color-*)`).
3. **Comportamentos e Interatividade (ES Modules)**:
   - Geração de código JavaScript limpo para manipulação de eventos declarativos (`click -> navigate`, `toggle`, handlers de estado).
4. **Isolamento e Anti-Monólito**:
   - Serviço autocontido com menos de 250 linhas de código.
   - Testes unitários validando geração de componentes isolados, slots aninhados e telas completas.
