# EP-12.18: Decompositor de telas para screens/*.html estruturados

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.17
- **Bloqueia:** 12.19, 12.20

## 2. Contexto
No monólito `Main.dc.html`, todas as telas e diálogos estavam embutidos em um único template de 587 linhas intercalado com diretivas `<sc-if>` e `<sc-for>`, impedindo a visualização isolada e a renderização rápida.

## 3. Objetivo
Implementar um decompositor que divide o fluxo em telas semânticas independentes (`home.html`, `dispensacao.html`, `historico.html`), injetando marcação limpa com atributos `data-node-id="node-X"` para inspeção visual 1:1, sem os scripts destrutivos do DataChef.

## 4. Requisitos
**Funcionais**
- RF1: Decompor fluxos em telas individuais salvas em `screens/<screenId>.html`.
- RF2: Substituir tags proprietárias DataChef por cascas HTML semânticas (`<div data-node-id="node-X" data-component="dis.xyz">`).
- RF3: Injetar atributos `data-node-id` para permitir clique e seleção bidirecional no Ateliê e Studio.
- RF4: Gerar HTML limpo, compatível com os tokens de design do DIS.

**Nao funcionais**
- Arquivo conciso (< 250 linhas).
- Não alterar os arquivos de origem (apenas ler e emitir no destino modular).

## 5. Implementacao
1. Criar `ui/server/services/prototype-screen-decomposer.service.js`.
2. Implementar função `decomposeScreenHtml(rawTemplate, nodesMap)`.
3. Escrever testes unitários de renderização de fragmentos de tela.

## 6. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Unitario | Decompor template em HTML limpo com data-node-id | `node --test tests/prototype-screen-decomposer.test.js` |

## 7. Criterios de aceite
- [x] Telas geradas em `screens/` são HTML semântico limpo.
- [x] Atributos `data-node-id` correspondem com exatidão aos IDs do mapa de nós.

## 8. Evidencias
- `ui/server/services/prototype-screen-decomposer.service.js`: remoção de tags proprietárias DataChef, substituição por `<div data-node-id="node-X">` e estruturação de telas.
- `tests/prototype-screen-decomposer.test.js`: 100% dos testes aprovados.
