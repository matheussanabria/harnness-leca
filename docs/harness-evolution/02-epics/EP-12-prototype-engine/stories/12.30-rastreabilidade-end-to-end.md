# História 12.30 — Rastreabilidade End-to-End (Tela → Nó → Componente → Código)

## Status: Concluída
- **Fase**: F7 — Studio, Rastreabilidade e Piloto
- **Épico**: EP-12 — Prototype Engine & Design System Multiframework
- **Entrega**: Mecanismo de rastreabilidade reversa e direta (`prototype-traceability.service.js`) capaz de, a partir de qualquer clique em tela ou nó da árvore, resolver o grafo completo: Tela -> Nó Semântico -> Componente no Registry -> Boilerplates do Design System -> Código Gerado nos 3 Frameworks (Vanilla, Angular 18 e React 18+).

---

## 1. Contexto e Motivação
A maior dor em prototipação e transição para engenharia é a perda de rastreabilidade entre o que está visível na tela e qual componente, token ou linha de código origina aquele comportamento.
A rastreabilidade end-to-end fecha esse elo: qualquer elemento selecionado no inspetor do protótipo expõe instantaneamente qual componente do Design System o originou, seu contrato de props, sua documentação e seu código equivalente nos três frameworks suportados.

---

## 2. Requisitos e Critérios de Aceite
1. **Resolução de Grafo Completo**:
   - `resolveNodeTraceability(projectDir, protoId, screenId, nodeId)`:
     - Localiza a tela e o nó no `proto.json` v2.
     - Obtém metadados do componente no `registry.json` do Design System.
     - Mapeia implementações e boilerplates disponíveis no disco.
     - Gera snippets de código em tempo real para Vanilla, Angular 18 e React 18+.
2. **Suporte a Componentes Nativos e Customizados**:
   - Resolução resiliente tanto para componentes oficiais (`dis.*`, `layout.*`) quanto elementos HTML nativos.
3. **Respeito aos Limites Arquiteturais**:
   - Código mantido estritamente abaixo do teto de 250 linhas.
   - Suíte de testes automatizados comprovando a resolução completa de rastreabilidade.
