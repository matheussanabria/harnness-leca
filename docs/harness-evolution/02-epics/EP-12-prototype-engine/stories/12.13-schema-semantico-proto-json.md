# EP-12.13: Especificar schema semantico estendido do proto.json

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.03, 12.05
- **Bloqueia:** 12.14, 12.15, 12.16, 12.17

## 2. Contexto
No formato original de protótipo (`proto.json` v1), o arquivo continha apenas referências rasas de arquivos HTML estáticos sem qualquer mapa semântico dos nós, dificultando a inspeção seletiva, a mutação de propriedades e a geração de código limpo para múltiplos frameworks (Angular e React).

## 3. Objetivo
Formalizar a especificação canônica do `proto.json` v2.0.0 com JSON Schema oficial e tipagens completas, suportando:
- Metadados do protótipo (`metadata`)
- Telas indexadas (`screens`)
- Árvore canônica indexada de nós (`PrototypeNode`)
- Identidade de componente associada ao Design System Registry (`componentId`)

## 4. Requisitos
**Funcionais**
- RF1: Criar arquivo de JSON Schema oficial `schemas/prototype-v2.schema.json`.
- RF2: Garantir que cada nó (`PrototypeNode`) possua `id`, `componentId`, `props`, `bindings`, `events`, `slotTargets` e `children`.
- RF3: Suportar mapa de nós indexados `nodes: Record<string, PrototypeNode>` para acesso O(1).
- RF4: Compatibilidade com protótipos existentes através de detecção de versão (`schemaVersion: "2.0.0"`).

**Nao funcionais**
- Especificação rigorosa em conformidade com JSON Schema Draft 7 ou 2020-12.
- Nenhuma dependência externa de runtime obrigatória para parsing básico.

## 5. Implementacao
1. Escrever `schemas/prototype-v2.schema.json`.
2. Criar serviço leve de leitura/normalização de `proto.json` em `ui/server/services/prototype-schema.service.js`.
3. Escrever testes unitários de conformidade do schema.

## 6. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Unitario | Validar estrutura do schema v2 e normalização de nós | `node --test tests/prototype-schema.test.js` |

## 7. Criterios de aceite
- [x] Arquivo `schemas/prototype-v2.schema.json` criado e válido.
- [x] Serviço de normalização garante árvore indexada O(1).
- [x] 100% dos testes unitários passando.

## 8. Evidencias
- `schemas/prototype-v2.schema.json`: JSON Schema formal draft-07 com definições de `metadata`, `screens`, `nodes` e `PrototypeNode`.
- `ui/server/services/prototype-schema.service.js`: criação, indexação O(1) e hidratação de árvore.
- `tests/prototype-schema.test.js`: 100% dos testes passando sem erros.
