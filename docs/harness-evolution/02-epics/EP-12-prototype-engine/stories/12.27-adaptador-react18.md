# História 12.27 — Adaptador React 18+ (Hooks & Componentes Funcionais)

## Status: Concluída
- **Fase**: F6 — Adaptadores Multiframework (Vanilla, Angular 18 e React 18+)
- **Épico**: EP-12 — Prototype Engine & Design System Multiframework
- **Entrega**: Adaptador gerador de código React 18+ (`prototype-codegen-react.service.js`) a partir da árvore semântica do `proto.json` v2, gerando componentes funcionais modernos com TypeScript/JSX, hooks de estado (`useState`), props de slots tipados e compatibilidade com CSS Modules e Tailwind.

---

## 1. Contexto e Motivação
A geração de código para React 18+ requer componentes puramente funcionais, tipagem clara em TypeScript (TSX), uso idiomático de hooks para gerenciamento de estado e estruturação declarativa de slots e children via props composíveis.

---

## 2. Requisitos e Critérios de Aceite
1. **Componentes Funcionais Idiomáticos**:
   - Geração de componentes funcionais limpos (`export function <Nome>Screen() { ... }`).
   - Uso de `useState` inicializado com os dados declarados em `screen.initialState`.
2. **JSX Declarativo e Atributos**:
   - Conversão de `class` para `className`, `for` para `htmlFor`.
   - Conversão de bindings de estado para `{state.prop}` ou `title={state.user?.nome}`.
   - Eventos de clique compilados como `onClick={() => handleNavigate('...')}`.
3. **Composição de Slots**:
   - Mapeamento de slots nomeados para blocos JSX ou subcomponentes dedicados.
4. **Isolamento Arquitetural**:
   - Arquivo contido estritamente abaixo do teto de 250 linhas.
   - Suíte de testes unitários automatizados validando JSX, hooks e estrutura TSX.
