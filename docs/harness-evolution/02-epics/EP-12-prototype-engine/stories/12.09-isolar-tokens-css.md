# EP-12.09: Isolar CSS global, temas e tokens semanticos

## 1. Identificacao
- **Epico:** [EP-12](../README.md)
- **Prioridade:** P0
- **Dependencias:** 12.05, 12.06
- **Bloqueia:** 12.10, 12.11

## 2. Contexto
No monólito `dis-design-system.html`, centenas de variáveis CSS, cores de escala, tokens de espaçamento, tipografia e regras de tema claro/escuro estão embutidas dentro de uma única tag `<style>` de 1798 linhas misturadas com demonstrações de componentes.

## 3. Objetivo
Extrair e modularizar os tokens de design do DIS em folhas de estilo limpas e desacopladas:
- `projects/<slug>/design/ds/tokens.css` (Variáveis CSS de cores, escalas, espaçamentos e fontes)
- `projects/<slug>/design/ds/theme.css` (Mapeamentos semânticos `:root` e `[data-theme="light"]`)

## 4. Requisitos
**Funcionais**
- RF1: Isolar todas as variáveis de paleta pura (`--pure-0`, `--blue-*`, `--gray-*`, `--red-*`, etc.).
- RF2: Isolar tokens semânticos (`--primary-*`, `--neutral-*`, `--highlight-*`, `--danger-*`, `--success-*`, etc.).
- RF3: Fornecer fonte tipográfica Noto Sans e estilos base de reset.

**Nao funcionais**
- Arquivos CSS bem organizados e comentados.
- Sem efeitos colaterais de estilos específicos de componentes embutidos nos tokens.

## 5. Implementacao
1. Extrair bloco de variáveis de `dis-design-system.html`.
2. Salvar `projects/saude-dispensacao/design/ds/tokens.css` e `theme.css`.
3. Validar sintaxe CSS e inclusão de tokens.

## 6. Testes
| Tipo | Cenario | Comando ou arquivo |
|---|---|---|
| Unitario | Checar existência e integridade dos arquivos de tokens | `node --test tests/design-tokens.test.js` |

## 7. Criterios de aceite
- [x] `tokens.css` e `theme.css` gerados no diretório `ds/`.
- [x] Variáveis semânticas essenciais presentes e válidas.

## 8. Evidencias
- `projects/saude-dispensacao/design/ds/tokens.css`: 119 linhas com todas as escalas puras, espaçamentos, raios e tipografia.
- `projects/saude-dispensacao/design/ds/theme.css`: 69 linhas com mapeamento semântico light theme e reset limpo.
- `tests/design-tokens.test.js`: 100% dos testes passando sem falhas.
