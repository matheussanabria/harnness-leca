# EP-08.08: Renderização de Diagramas Mermaid nos Workflows e Catálogo

[Voltar ao épico](./README.md)

- **Épico:** [EP-08](./README.md)

- **Bloqueia:** nenhum.

## 2. Contexto
Os arquivos de documentação de workflows (como `WORKFLOW.md` e dossiês de etapas) frequentemente contêm diagramas de máquinas de estados e transições em blocos ` ```mermaid `. No visualizador Markdown do Catálogo (`catalogo-browser.js`), esses blocos eram processados como simples caixas de texto com cabeçalho `MERMAIDmermaid`, sem a devida interpretação vetorial do Mermaid.js.

## 3. Objetivo
Permitir a visualização interativa e elegante de diagramas Mermaid (como `stateDiagram-v2`, `flowchart` e `sequenceDiagram`) diretamente nos documentos de workflows e arquivos Markdown do catálogo, com suporte a tema dark, alternância para código fonte original, botão de cópia e tratamento seguro contra erros de sintaxe.

## 4. Requisitos
**Funcionais**
- RF1: Blocos de código com linguagem `mermaid` são detectados e encapsulados em um card `.mermaid-card`.
- RF2: Renderização SVG via biblioteca Mermaid nativa com tema escuro consistente com o design system do Harness.
- RF3: Botão de alternância para o usuário inspecionar o código fonte bruto do diagrama (`fa-solid fa-code`) e voltar para a visualização gráfica (`fa-solid fa-diagram-project`).
- RF4: Botão de cópia para a área de transferência com ícones FontAwesome (`fa-regular fa-copy`).
- RF5: Tratamento de exceção gracioso caso o diagrama possua sintaxe incorreta, mantendo o layout e exibindo mensagem amigável sem quebrar o restante da página.

**Não-funcionais**
- Aderência estrita à segurança do Mermaid conforme **ADR-014** (`securityLevel: "strict"`, sem HTML labels e sem callbacks arbitrários).
- Ausência absoluta de emojis (FontAwesome exclusivo).
- Arquivos modulares mantidos estritamente abaixo do teto de 250 a 300 linhas.
- Carregamento lazy/sob demanda do pacote Mermaid para não penalizar o tempo de carga inicial.

## 5. Arquitetura
```
[markdown-code.js]        Detecta linguagem mermaid e monta o container estruturado (.mermaid-card)
        |
[mermaid-renderer.js]     Módulo assíncrono: instancia Mermaid com tema dark e executa mermaid.render()
        |
[mermaid.css]             Estilização dark, viewport com scroll horizontal e botões de ação
        |
[catalogo-browser.js]     Dispara a renderização dos nós .mermaid após pintar o viewer
```
