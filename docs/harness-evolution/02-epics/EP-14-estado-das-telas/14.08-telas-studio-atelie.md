# EP-14.08: Adoção no Studio e no Ateliê

## 1. Identificação
- **Épico:** [EP-14](README.md)
- **Prioridade:** P1
- **Dependências:** 14.05, 14.06
- **Branch:** `ep14/14.08-telas-studio-atelie`

## 2. Contexto
Larguras, colunas, tela e protótipo ativos, nó selecionado e recolhimento do chat se perdem ou ficam só no navegador.

## 3. Objetivo
O Studio e o Ateliê restauram o último estado após F5.

## 4. Requisitos
- Persistir: protótipo e tela ativos, nó selecionado, painéis recolhidos, largura da sidebar, viewport.
- Registrar ações: salvar arquivo, aplicar edição, excluir protótipo.

## 5. Arquivos que esta história pode tocar
- ui/public/js/modules/studio-*.js
- ui/public/js/modules/prototype-*.js
- tests/**
- ui/server/services/screen-state/registry.js (somente acrescentar campos e chaves `migraDe` das telas desta história; não alterar as demais entradas)

Tocar fora desta lista exige registrar o motivo na história. Cada arquivo novo fica abaixo de 300 linhas, sem emojis (ícones FontAwesome) e com linha no `MAPA.md`.

## 6. Testes
Teste de regressão para cada comportamento novo; `npm test` verde ao final.

## 7. Critérios de aceite
- [ ] F5 no Ateliê reabre o mesmo protótipo, tela e painéis.
- [ ] `npm test` passa na branch `ep14/14.08-telas-studio-atelie` antes do merge.
- [ ] `MAPA.md` atualizado com os arquivos novos.
