# EP-14.03: Executor de pacotes do opencode em worktree

## 1. Identificação
- **Épico:** [EP-14](README.md)
- **Prioridade:** P0
- **Dependências:** nenhuma
- **Branch:** `ep14/14.03-executor-opencode`

## 2. Contexto
`tools/lib/llm.js` roda o opencode só com leitura, em pasta vazia e com modelo `-free`. Isso serve para extração, mas não para entregar código.

## 3. Objetivo
`node tools/opencode-package.js <história>` cria uma branch e um worktree por pacote, roda o opencode com escrita só ali e devolve o diff.

## 4. Requisitos
- Cria `git worktree` em `C:/Temp/hl-<id>` (caminho curto, por causa do limite do Windows) na branch `ep14/<id>-<slug>`, a partir da branch base informada.
- Monta um `opencode.json` temporário com escrita restrita ao worktree, modelo `-free` fixo (override só com `--allow-paid`) e a história como prompt.
- Lê da história a lista de arquivos permitidos, os comandos de teste e as regras do repositório.
- Ao final roda `git diff --stat`, falha se tocar arquivo fora da lista e registra o resultado em `docs/harness-evolution/05-progress/multi-agent-sync.md` como `opencode/<id>`.
- Não commita nem faz merge: devolve o worktree para revisão.

## 5. Arquivos que esta história pode tocar
- tools/opencode-package.js
- tools/lib/opencode-package/*.js
- tests/opencode-package.test.js
- MAPA.md

Tocar fora desta lista exige registrar o motivo na história. Cada arquivo novo fica abaixo de 300 linhas, sem emojis (ícones FontAwesome) e com linha no `MAPA.md`.

## 6. Testes
Teste de regressão para cada comportamento novo; `npm test` verde ao final.

## 7. Critérios de aceite
- [ ] Um pacote de teste (arquivo trivial) é criado no worktree e a tentativa de editar fora da lista é recusada.
- [ ] `npm test` passa na branch `ep14/14.03-executor-opencode` antes do merge.
- [ ] `MAPA.md` atualizado com os arquivos novos.
