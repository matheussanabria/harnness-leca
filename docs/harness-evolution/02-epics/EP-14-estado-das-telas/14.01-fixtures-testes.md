# EP-14.01: Fixtures de teste independentes de projects/

## 1. Identificação
- **Épico:** [EP-14](README.md)
- **Prioridade:** P0
- **Dependências:** nenhuma
- **Branch:** `ep14/14.01-fixtures-testes`

## 2. Contexto
Cerca de 12 arquivos de teste leem `projects/saude-dispensacao` (no `.gitignore`) e dependem de protótipos locais como `dis-modular`. Quando o usuário exclui um protótipo pelo Ateliê, 26 testes falham e o pre-commit bloqueia. Três testes de `tests/design-routes.test.js` estão em `test.skip` por isso.

## 3. Objetivo
Os testes criam o próprio projeto numa pasta temporária e não leem mais `projects/`.

## 4. Requisitos
- `tests/helpers/project-fixture.js`: cria um projeto temporário com `design.json`, `design/prototypes/dis-modular`, `design/ds` e o que os testes pedem; devolve `{ dir, slug, cleanup }`.
- Migrar os testes que citam `SAUDE_DIR` ou `projects/saude-dispensacao` (lista por `grep -l`) para o helper.
- Reativar os 3 `test.skip` de `design-routes`.
- `tests/hia-registry.test.js` ("executa coordination.status") depende do projeto ativo em `projects/.active`: fixar o projeto no teste (ou no fixture) para passar com qualquer projeto ativo.
- O router passa a aceitar a raiz de projetos por variável (`HARNESS_PROJECTS_DIR`); sem ela, o comportamento atual.

## 5. Arquivos que esta história pode tocar
- tests/helpers/**
- tests/*.test.js (somente os que leem projects/)
- ui/server/config.js (leitura da raiz de projetos)

Tocar fora desta lista exige registrar o motivo na história. Cada arquivo novo fica abaixo de 300 linhas, sem emojis (ícones FontAwesome) e com linha no `MAPA.md`.

## 6. Testes
Teste de regressão para cada comportamento novo; `npm test` verde ao final.

## 7. Critérios de aceite
- [ ] `npm test` passa com `projects/saude-dispensacao` renomeada; nenhum `test.skip` por dados locais; nenhum teste escreve em `projects/`.
- [ ] `npm test` passa na branch `ep14/14.01-fixtures-testes` antes do merge.
- [ ] `MAPA.md` atualizado com os arquivos novos.
