# EP-20: Responsividade e edição móvel

[Voltar ao índice](../../00-index.md)

## Objetivo

Tornar os fluxos essenciais do Harness utilizáveis em telas móveis sem comprimir experiências de desktop em uma mesma área visual.

## Contexto

O Studio já permite listar, abrir, editar e salvar arquivos-fonte com confinamento de caminho, bloqueio de segredos e controle otimista de conflito. Entretanto, a regra de estilo atual oculta a coluna de código abaixo de 768px, removendo esse fluxo do celular.

## Entrega inicial

Uma experiência de edição de código-fonte no celular, em tela dedicada, que preserve as proteções de gravação e permita voltar para preview ou chat.

## Aceite do épico

Pessoas usuárias conseguem editar e salvar código-fonte pelo celular no Studio sem perda silenciosa de alterações e sem ampliar a área de arquivos editáveis.
