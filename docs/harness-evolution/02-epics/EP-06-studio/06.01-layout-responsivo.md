# EP-06.01: Layout responsivo e redimensionamento do Studio (HAR-006)

## 1. Identificação
- **Épico:** [EP-06](README.md)
- **Prioridade:** P1
- **Dependências:** EP-02.04 (Apresentação lateral do chat unificado), EP-04.01 (Seleção centralizada de projeto)
- **Bloqueia:** EP-06.02, EP-06.03

## 2. Contexto
O Studio do Harness unifica a experiência de desenvolvimento e vibecoding com IA, integrando chat lateral, canvas interativo, explorador de código e sandbox de preview da aplicação.
Anteriormente (Fase 2 / backlog legado HAR-006), havia estilos preliminares de redimensionamento e código embutido de forma monolítica em `studio-core.js`, sem documentação formal, sem suíte de testes unitários isolada e sem garantia de persistência desacoplada por projeto.

## 3. Objetivo
Fornecer um controlador de layout e redimensionamento robusto, acessível e responsivo para o Studio:
1. Splitter vertical com arraste contínuo via Pointer Events (compatível com mouse e touch).
2. Garantia de limites mínimos de tela (`STUDIO_SIDEBAR_MIN = 300px`, `STUDIO_CANVAS_MIN = 300px`, `STUDIO_SIDEBAR_MAX = 850px`).
3. Suporte completo a teclado (ARIA `role="separator"`, `ArrowLeft`/`ArrowRight`, `PageUp`/`PageDown`, `Home`/`End`).
4. Duplo clique no splitter para restauração instantânea da largura padrão (440px).
5. Persistência da largura no storage local por projeto com fallback seguro.
6. Desacoplamento arquitetural estrito: módulo dedicado `studio-layout.js` (< 200 linhas) sem misturar regras de negócio do Studio.

## 4. Requisitos
**Funcionais**
- RF1: Calcular limites responsivos baseados no viewport atual (`calculateSidebarBounds`), impedindo que o canvas seja esmagado.
- RF2: Limitar largura solicitada (`clampSidebarWidth`) dentro do intervalo `[min, max]`.
- RF3: Persistir a largura com chave isolada por projeto (`resolveStorageKey`, `saveStoredSidebarWidth`) e recuperar no carregamento (`getStoredSidebarWidth`).
- RF4: Atualizar atributos de acessibilidade no splitter (`aria-valuenow`, `aria-valuemin`, `aria-valuemax`).
- RF5: Duplo clique no resizer restaura a largura padrão canônica de 440px.
- RF6: Navegação por teclado: teclas de seta alteram em passos de 16px; PageUp/PageDown em 64px; Home vai para min; End vai para max.

**Não funcionais**
- Arquivos de até 300 linhas, SRP rígido.
- Ícones apenas FontAwesome. Nenhum emoji.
- Não introduzir regressão no modo 2.5D ou painel principal.

## 5. Arquitetura
- **Módulo controlador:** `ui/public/js/modules/studio-layout.js` (responsabilidade única de splitter, bounds e persistência).
- **Integração no ciclo de vida:** Chamado por `ui/public/js/modules/studio-core.js` no `syncStudioControls()` ao alternar para o Studio.
- **Fachada pública:** Reexportado por `ui/public/js/modules/studio.js`.
- **Estilos CSS:** `ui/public/css/chat-mobile.css` (`.studio-sidebar-resizer`, `.studio-resizing`).

## 6. Implementação
1. Extrair a lógica de redimensionamento e cálculo de bounds de `studio-core.js` para `studio-layout.js`.
2. Implementar helpers puros testáveis: `calculateSidebarBounds`, `clampSidebarWidth`, `resolveStorageKey`, `getStoredSidebarWidth`, `saveStoredSidebarWidth` e `applySidebarWidth`.
3. Adicionar evento `dblclick` para reset rápido para 440px e teclas `PageUp`/`PageDown`.
4. Atualizar `studio-core.js` e `studio.js` mantendo a retrocompatibilidade completa da API.
5. Criar testes unitários em `tests/studio-layout.test.js`.

## 8. Critérios de aceite
- [x] Limites de redimensionamento respeitam largura mínima de 300px da sidebar e do canvas.
- [x] Teclado ARIA suporta ArrowLeft, ArrowRight, PageUp, PageDown, Home e End.
- [x] Persistência funciona por projeto e restaura a largura salva.
- [x] Código desacoplado em `studio-layout.js` com menos de 200 linhas.
- [x] 100% dos testes passando na suíte global.

## 9. Riscos
- **Compatibilidade:** Totalmente retrocompatível com navegadores legados (verificação condicional de Pointer Events e releasePointerCapture).
- **Segurança:** Nenhum dado sensível gravado em storage; chaves prefixadas evitam colisão.
- **Rollback:** Restaurar `studio-core.js` anterior e remover `studio-layout.js`.
