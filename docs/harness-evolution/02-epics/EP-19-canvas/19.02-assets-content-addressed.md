# EP-19.02: Canvas content-addressed assets

Previously labelled 16.02 (ADR-011). Implemented in main; commits 5f90bec and e30e213.

## Objective
Let boards reference uploaded files (images, documents) stored by content hash, served only from the board's own folder.

## Requirements
- `POST /api/canvas/boards/:id/assets` and `GET /api/canvas/boards/:id/assets/<sha256>.<ext>`; stored in `canvas/<boardId>/assets/`.
- File type decided by magic bytes (png, jpg, gif, webp, pdf; txt, md, csv, json by name plus UTF-8 check). No SVG.
- Dedupe by sha256; 200 MB quota per board; atomic write; symlink-guarded folders.
- Upload checks the board before reading the body; Content-Length checked first and reading stops when the limit is crossed.
- Download uses a fixed Content-Type, nosniff, sandbox CSP and inline/attachment disposition.
