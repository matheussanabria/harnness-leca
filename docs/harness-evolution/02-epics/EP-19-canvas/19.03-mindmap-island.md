# EP-19.03: Mind-map island

Previously labelled 16.03 (ADR-011). Also requires the frontend foundation (ADR-011 step 1, "16.00").

## Objective
A React island to create and edit mind maps stored through the 19.01 REST API, with a semantic tree model independent of graphic ids.

## Requirements
- Model: tree of nodes (id, parent, text, collapsed), pure TypeScript, no DOM.
- Commands: Enter adds a sibling, Tab adds a child, Shift+Tab outdents; drag-reparent with a cycle guard (a node cannot move under its own descendant); collapse and expand.
- Undo and redo over commands.
- Layout with d3-hierarchy; rendering with React Flow.
- Load and save through `/api/canvas/boards` using `rev` (handle conflict by reloading).
- Island follows the mount/unmount contract from ADR-011.

## Files
- ui/web/src/islands/canvas-mindmap/**
- ui/web/src/features/mindmap/**
- docs/mapa/frontend/web/ (map entry), new npm dependencies pinned exactly and reviewed.

## Tests
Unit tests for model, commands, cycle guard and undo/redo; `tsc -p ui/web`; `npx biome check ui/web`; E2E open, edit and reopen.
