# EP-19.07: Mind-map chat: outline parser and chat bridge

## Objective
Let the Studio chat create and expand a mind map: the answer carries a `<mindmap>` bullet outline that becomes nodes.

## Requirements
- Pure `parseOutline` (indentation stack, text cleaning, 200-node and 8-level caps, code fences ignored) and `appendOutline` / `replaceWithOutline` (immutable, id retry, document cap).
- Legacy bridge hooked into `prototype-chat-bridge.js` and `chat-persist.js`: adds the rules and the current map to the prompt (rules once per session, the map when it changed), extracts `<mindmap parent="selected|root" mode="append|new">` blocks and hands them to the island by event.
- The chat is "embedded-active" so a finished turn does not reload the project and rewrite the chat.

## Delivered
Commit 5c15885 on `feat/canvas-chat`. Map: `canvas-mindmap.md` and `canvas-workspace.md`.

## Tests
