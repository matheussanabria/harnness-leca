# EP-19.05: Selection to agent context pack

Previously labelled 16.05 (ADR-011).

## Objective
Turn the current selection of a mind map into a compact context pack an agent can consume.

## Requirements
- Output both Markdown (human and prompt friendly) and JSON (structured) from the same selection.
- Deterministic char budget: same selection and budget always yield the same output; truncation order is defined and documented, and the pack states when content was cut.
- Pure function over the 19.03 model, no network.
- Pack contains identifiers and text only; no secrets are added.

## Files
- ui/web/src/features/context-pack/**
- docs/mapa/frontend/web/ (map entry)

## Tests
Unit tests: determinism, budget boundaries, truncation marker, empty selection, Markdown/JSON parity.
