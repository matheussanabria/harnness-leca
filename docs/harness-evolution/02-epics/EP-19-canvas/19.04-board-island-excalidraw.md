# EP-19.04: Board island with Excalidraw

Previously labelled 16.04 (ADR-011). Also requires the frontend foundation (ADR-011 step 1, "16.00").

## Objective
A lazy-loaded React island hosting Excalidraw for free-form boards, persisted through the 19.01 API.

## Requirements
- Save and reopen a board; send `rev` on save and handle a conflict without silent overwrite.
- Export (PNG and/or JSON); the exact formats are decided in the story kickoff and confirmed against the Excalidraw version pinned.
- Images and files are uploaded through the 19.02 asset endpoints and referenced by hash.
- Island is lazy-loaded; the main shell must not import it.
- Mount/unmount contract from ADR-011.

## Files
- ui/web/src/islands/canvas-board/**
- docs/mapa/frontend/web/ (map entry)

## Tests
`tsc -p ui/web`; `npx biome check ui/web`; unit tests for the save/rev adapter; E2E draw, save, reload, image round trip.

## Delivered beyond the first scope
Server fix so PUT, DELETE and asset upload work through the real server (`/api/canvas/*`), pinned `overrides` for audit findings. Open: no committed UI test (only throwaway browser scripts), font fallback URLs blocked by the CSP (harmless console noise), SVG images refused by design.
