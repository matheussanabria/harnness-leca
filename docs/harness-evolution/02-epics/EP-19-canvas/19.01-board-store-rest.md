# EP-19.01: Canvas board store and REST API

Previously labelled 16.01 (ADR-011). Implemented in main; commits a2a8d43 and c0abb43.

## Objective
Persist boards and mind maps per project on the server with atomic writes, optimistic concurrency and versioned migrations.

## Requirements
- Boards in `projects/<slug>/canvas/<uuid>.json` with a rebuildable `index.json`; delete moves the file to `.trash/`.
- `data` is opaque JSON, capped at 4 MB; `rev` checked on update (conflict on mismatch).
- Atomic write (tmp file then rename), no symlinks, no path built from unvalidated input.
- Versioned migrations; files from a newer version are refused (`UNSUPPORTED_VERSION`); a `.v<N>.bak.json` is written before the first migration rewrite.
- API: `GET/POST /api/canvas/boards`, `GET/PUT/DELETE /api/canvas/boards/:id`; errors as `{ error, code }`, 400 for invalid JSON, 413 for oversize.
