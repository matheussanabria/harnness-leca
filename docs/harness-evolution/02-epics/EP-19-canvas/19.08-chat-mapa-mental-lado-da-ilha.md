# EP-19.08: Mind-map chat: island side

## Objective
The mind-map island publishes its state to the chat and applies the blocks of the answer as one undoable step.

## Requirements
- `harness:canvas-state` carries board id, title, selected node and the whole map as an outline (bounded); published debounced and cleared on unmount.
- `harness:canvas-apply` blocks are applied to the latest document in one history entry; the first new node gets the focus; unknown boards and malformed events are ignored.

## Delivered
Commit c5ee820 on `feat/canvas-chat`. Verified end to end through the real chat bridge: prompt content, append of four nodes, one undo, `mode="new"`, persistence.

## Tests
`mindmap-chat-bridge.test.js`; browser check of the full flow with a simulated answer.
