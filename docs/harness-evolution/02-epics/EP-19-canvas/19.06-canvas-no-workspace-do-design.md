# EP-19.06: Canvas inside the Design workspace

## Objective
Show the mind map and the board as views of the Design workspace, in the same three-column layout as the Atelier, instead of full-screen islands.

## Requirements
- Tabs "Mapa mental" and "Quadro livre" in the Design header; routes `#/canvas-mindmap` and `#/canvas-board` are Design views; both are registered in the screen registry (server and client mirror).
- The island loader mounts an island into a target element and passes `embedded: true`; leaving the view or closing the Design unmounts it.
- Left column: board catalog (create, rename inline, delete with in-place confirmation, select) reusing the prototype catalog classes. Middle: the Studio chat dock (same ids and helpers as the Atelier, so resize, collapse and minimize work). Right: the editor of the selected board; an empty state when none is selected.
- Embedded islands show only the editor (no own list, no back button).

## Delivered
Branches `feat/canvas-embedded-views` and `feat/canvas-workspace` (commits 912f70d, aa3f4ec, 42476e2). Map: `docs/mapa/frontend/canvas/canvas-workspace.md` and `canvas-design-embed.md`.

## Tests
Loader with a target, router and registry parity (server and client), catalog API and markup (escaping, states), workspace skeleton ids and classes. Browser check: tabs, create, rename, delete, switching tabs keeps the chat.
