# EP-13.08: Colheita das memórias nativas para a oficina

## 1. Identificação
- **Épico:** [EP-13](README.md)
- **Prioridade:** P2
- **Dependências:** 13.01, 13.05
- **Bloqueia:** nenhuma

## 2. Contexto
Cada motor aprende por conta própria: o Claude Code grava em `~/.claude/projects/<dir>/memory/`, o Gemini CLI em `~/.gemini/GEMINI.md` (seção `## Gemini Added Memories`). Depois da 13.01 isso deixa de ser apagado, mas continua fora do harness e fica preso a um motor.

## 3. Objetivo
O que um motor aprendeu vira candidato na tela de revisão e, aprovado, passa a valer para todos os motores.

## 4. Requisitos
**Funcionais**
- RF1. `node tools/memory.js harvest [--project <slug>] [--engine claude|gemini]` lê, somente leitura:
  - Claude: arquivos `*.md` da pasta de memória sem `harness:generated` e linhas do `MEMORY.md` fora do bloco gerenciado;
  - Gemini: bullets da seção `## Gemini Added Memories`.
- RF2. Projeto do Claude resolvido pelo mesmo mapeamento de pasta usado no export (`claudeDirsBySlug`).
- RF3. Grava candidatos em `projects/<slug>/context/colhido-nativo.md` no formato que a revisão já lê, com `source: harvest:<motor>:<arquivo>`.
- RF4. Candidato com hash ou similaridade igual a item curado não entra.
- RF5. Passa pelo `guard.js` antes de gravar; segredo vira aviso, não candidato.
- RF6. Nunca altera nem apaga nada na pasta do motor.

**Não funcionais**
- Rodável pelo `sync` existente, atrás de uma flag, sem chamada a modelo.

## 5. Arquitetura
`tools/lib/memory/harvest/{claude,gemini}.js`, cada um devolvendo `{ texto, origem }[]`; a gravação reusa a escrita de sugestões da oficina.

## 6. Implementação
1. Leitores por motor com fixtures.
2. Filtro por dedupe e guard.
3. Integração com a tela de revisão (a categoria aparece como "colhida").
4. Flag no `sync`.

## 7. Testes
| Tipo | Cenário | Comando ou arquivo |
|---|---|---|
| Unitário | Arquivo com `harness:generated` é ignorado | `node --test tests/memory-harvest.test.js` |
| Unitário | Fato já curado não vira candidato | idem |
| Unitário | Pasta do motor não é modificada (mtime e conteúdo) | idem |

## 8. Critérios de aceite
- [ ] Uma memória gravada pelo Claude Code aparece na revisão e, promovida, chega ao Knowledge Item do Gemini.
- [ ] Nenhuma escrita nas pastas dos motores.

## 9. Riscos
- **Privacidade:** memórias nativas podem ter dado pessoal; guard + redact antes de gravar.
- **Rollback:** desligar a flag e apagar `colhido-nativo.md`, com confirmação.
