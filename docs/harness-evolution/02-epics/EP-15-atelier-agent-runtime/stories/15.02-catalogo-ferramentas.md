# 15.02 - Catálogo de Ferramentas Nativas do Ateliê

## Contexto
Para libertar os modelos de IA da obrigação de cuspir blocos monolíticos de HTML/CSS em texto corrido (que estouram o limite de 8.192 tokens por turno), precisamos expor um conjunto de **ferramentas atômicas e estruturadas** específicas para prototipação.

## Escopo da Entrega
1. Criar `ui/server/services/atelier-tools.service.js` definindo os schemas e executores das seguintes ferramentas:
   - `atelier_plan`:
     - Argumentos: `{ steps: Array<{ id: string, title: string, status: "pending" | "in_progress" | "done" }>, assumptions: string[] }`
     - Ação: Grava em `scratch/plan.json` e emite evento SSE de atualização do plano na tela.
   - `atelier_write_screen`:
     - Argumentos: `{ screenId: string, htmlContent: string, isPartial?: boolean }`
     - Ação: Escreve o fragmento sanitizado em `screens/<screenId>.html` sem recarregar o layout monolítico.
   - `atelier_patch_styles`:
     - Argumentos: `{ cssRules: string, mode: "append" | "replace" }`
     - Ação: Adiciona ou atualiza regras no `styles/proto.css`.
   - `atelier_ask_user`:
     - Argumentos: `{ question: string, options?: string[], context?: string }`
     - Ação: Suspende temporariamente o loop do agente e renderiza um card de pergunta interativo no chat do Ateliê.
   - `atelier_complete`:
     - Argumentos: `{ summary: string, changedFiles: string[] }`
     - Ação: Grava nova versão no histórico (`v1`, `v2`, etc.), limpa o scratchpad e emite recarga segura do iframe.
2. Criar `tests/atelier-tools.test.js` cobrindo validação de payloads, execução segura e tratamento de erros.

## Critérios de Aceite
- [x] Schemas das ferramentas são compatíveis tanto com formato OpenAI/OpenCode (`tools: [...]`) quanto com Gemini (`functionDeclarations: [...]`).
- [x] Execução das ferramentas é isolada e não propaga falhas para o servidor Node.
- [x] O código do serviço respeita o limite estrito de até 300 linhas (237 linhas).
- [x] 100% dos testes passam em `node --test tests/atelier-tools.test.js`.

## Evidências de Conclusão
- Criado `ui/server/services/atelier-tools.service.js` (237 linhas) com catálogo canônico e executores isolados:
  - `atelier_plan`: persistência do plano no `scratch/plan.json`.
  - `atelier_write_screen`: sanitização HTML e injeção automática de `data-pid` via `prototype-sanitizer.service`.
  - `atelier_patch_styles`: suporte a append incremental e replace do CSS.
  - `atelier_ask_user`: suspensão com sinal `yieldsControl: true` e payload de pergunta/opções.
  - `atelier_complete`: geração de versão no histórico e consolidação de metadados.
- Criado `tests/atelier-tools.test.js` com 5/5 testes aprovados cobrindo exportação de schemas, execução das 5 ferramentas e tratamento de erros.
