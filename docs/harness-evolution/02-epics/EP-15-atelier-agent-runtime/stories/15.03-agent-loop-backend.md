# 15.03 - Atelier Agent Loop & Tool Dispatcher (Backend)

## Contexto
Com o Scratchpad (15.01) e o Catálogo de Ferramentas (15.02) entregues, é necessário construir o **orquestrador do loop do agente**. Ele executa a conversa com o modelo em turnos contínuos até que o modelo emita `atelier_complete` ou suspenda a execução via `atelier_ask_user`.

## Escopo da Entrega
1. Criar `ui/server/services/atelier-agent-loop.service.js`:
   - `createAtelierAgentLoop({ slug, protoId, engine, model, maxTurns })`:
     - Gerencia o histórico da sessão de loop em memória.
     - Limita o número de passos por segurança (`maxTurns: 10` por padrão).
     - Executa o despachante de ferramentas (`executeAtelierTool`).
     - Emite chunks SSE em tempo real para a interface (`type: "tool_call"`, `type: "tool_result"`, `type: "plan_update"`, `type: "question"`).
     - Trata cancelamento via `AbortSignal`.
2. Criar `tests/atelier-agent-loop.test.js` cobrindo:
   - Ciclo de múltiplos turnos (plano $\to$ escrita $\to$ conclusão).
   - Suspensão de execução quando `yieldsControl: true` (`atelier_ask_user`).
   - Aborto por limite de passos (`maxTurns`).
   - Cancelamento limpo via `AbortSignal`.

## Critérios de Aceite
- [x] Orquestrador roda de forma assíncrona com suporte a AbortSignal.
- [x] Emite eventos de progresso estruturados para cada ferramenta executada.
- [x] Suspende e preserva o estado da sessão quando o modelo pergunta algo ao usuário (`atelier_ask_user`).
- [x] O código respeita o teto de 300 linhas por arquivo (138 linhas).
- [x] 100% dos testes passam em `node --test tests/atelier-agent-loop.test.js`.

## Evidências de Conclusão
- Criado `ui/server/services/atelier-agent-loop.service.js` (138 linhas) gerenciando:
  - Loop contínuo com histórico cumulativo de turnos (`role: "user" | "model" | "tool"`).
  - Teto de segurança de passos (`maxTurns`).
  - Despacho e encadeamento sequencial de ferramentas atômicas.
  - Suspensão imediata com devolução de controle ao usuário (`status: "yielded"`).
  - Cancelamento limpo sob `AbortSignal`.
- Criado `tests/atelier-agent-loop.test.js` com 3/3 testes automatizados aprovados (fluxo multi-turnos completo, suspensão interativa e aborto limpo).
