# 15.01 - Scratchpad & Workspace Temporário do Protótipo

## Contexto
Atualmente, qualquer alteração enviada pelo chat do Ateliê precisa ir diretamente para os arquivos finais (`screens/<id>.html`, `styles/proto.css`). Não existe um espaço de isolamento para o modelo gerar planos, notas de briefing, testes de fragmentos ou rascunhos preliminares antes da consolidação.

## Escopo da Entrega
1. Criar o serviço `ui/server/services/atelier-scratchpad.service.js`:
   - `getScratchDir(projectDir, protoId)`: Garante e retorna o caminho `.../scratch/`.
   - `writeScratchFile(projectDir, protoId, filename, content)`: Escreve arquivos de rascunho (ex: `plan.json`, `notes.md`, `wireframe.html`).
   - `readScratchFile(projectDir, protoId, filename)`: Lê arquivo do scratchpad.
   - `listScratchFiles(projectDir, protoId)`: Lista arquivos existentes no rascunho com metadata.
   - `cleanScratchDir(projectDir, protoId)`: Limpa arquivos temporários após conclusão do protótipo (se solicitado).
2. Endpoints na API:
   - `GET /api/project/:slug/design/prototypes/:protoId/scratch`
   - `GET /api/project/:slug/design/prototypes/:protoId/scratch/:filename`
3. Testes automatizados cobrindo criação, leitura, sanitização de caminhos (sem path traversal) e isolamento por protótipo.

## Critérios de Aceite
- [x] Cria diretório `projects/<slug>/design/prototypes/<protoId>/scratch/` sob demanda.
- [x] Bloqueia qualquer tentativa de path traversal (`..` ou caracteres especiais).
- [x] Arquivos em `scratch/` não afetam a renderização atual do iframe até serem promovidos.
- [x] Arquivo `ui/server/services/atelier-scratchpad.service.js` possui menos de 250 linhas (123 linhas).
- [x] Testes passam em `node --test tests/atelier-scratchpad.test.js`.

## Evidências de Conclusão
- Testes automatizados executados com sucesso em `tests/atelier-scratchpad.test.js` (3/3 testes passando).
- Rotas REST registradas em `ui/server/routes/design.routes.js`:
  - `GET /api/project/:slug/design/prototypes/:protoId/scratch`
  - `GET /api/project/:slug/design/prototypes/:protoId/scratch/:filename`
  - `POST /api/project/:slug/design/prototypes/:protoId/scratch/clean`
- Arquitetura estritamente modular e sem dependências pesadas, respeitando o teto de 300 linhas por arquivo.
