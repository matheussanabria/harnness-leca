# 15.05 - Interface Interativa do Ateliê (Frontend)

## Contexto
Com o Scratchpad (15.01), Ferramentas (15.02), Agent Loop (15.03) e Adaptadores (15.04) prontos no backend, conectamos o cliente do Ateliê (`ui/public/js/modules/`) para consumir o SSE do Agent Loop. A interface renderiza o plano em tempo real, exibe o status de execução de cada ferramenta e apresenta o cartão de interação quando o modelo fizer perguntas via `atelier_ask_user`.

## Escopo Entregue
1. Módulo frontend: `ui/public/js/modules/prototype-atelier-agent-ui.js` (160 linhas)
   - `renderAtelierPlanCard(plan)`: Renderiza o cartão com os passos (`pending`, `in_progress`, `done`) e suposições com ícones FontAwesome (`fa-circle-check`, `fa-spinner fa-spin`, `fa-regular fa-circle`).
   - `renderAtelierQuestionCard(questionPayload)`: Renderiza a pergunta interativa com botões de opções clicáveis e campo de contexto.
   - `renderAtelierToolBadge(toolName, status)`: Badge compacto indicando a ferramenta em execução sem poluir o chat.
   - `bindQuestionOptions(container, onSelect)`: Liga os cliques nas opções à resposta do chat.
2. Endpoint SSE no backend:
   - `POST /api/project/:slug/design/prototypes/:protoId/agent-run`:
     - Implementado em `ui/server/controllers/atelier-agent-run.controller.js` (162 linhas).
     - Dispara `createAtelierAgentLoop` conectado com o adaptador do motor ativo (Gemini ou OpenCode).
     - Transmite os eventos de progresso via Server-Sent Events (`plan_update`, `tool_start`, `tool_done`, `question`, `complete`).
3. Registrada a rota em `ui/server/routes/design.routes.js`.
4. Testes unitários cobrindo renderização HTML acessível, eventos SSE e ausência de emojis em `tests/prototype-atelier-agent-ui.test.js` (4/4 passando).

## Critérios de Aceite
- [x] Cartões de plano e perguntas utilizam exclusivamente FontAwesome (`fa-solid` / `fa-regular`), sem nenhum emoji.
- [x] Ao clicar em uma opção no card de pergunta, o texto é preenchido e despachado automaticamente no chat.
- [x] O código respeita o limite de 300 linhas por arquivo.
- [x] Testes passam em `node --test tests/prototype-atelier-agent-ui.test.js`.
