# 15.04 - Adaptadores de Motores para o Atelier Agent Loop

## Contexto
O orquestrador `createAtelierAgentLoop` espera uma função `modelTurn(history, signal)` que invoque a LLM enviando as ferramentas e receba as chamadas estruturadas de volta. Precisamos construir adaptadores específicos para:
1. **Gemini:** API do Google AI Studio com `tools: [{ functionDeclarations }]` e parsing de `part.functionCall`.
2. **OpenCode:** API REST local do OpenCode (`/session` ou prompts estruturados) com tool calling padrão OpenAI (`tools: [{ type: "function", ... }]`).
3. **Fallback Resiliente:** Parser de blocos estruturados caso o modelo responda em formato de texto delimitado ou JSON.

## Escopo da Entrega
1. Criar `ui/server/services/atelier-engine-adapters.service.js`:
   - `buildGeminiModelTurn({ key, model, systemPrompt, effort })`: Constrói o invocador compatível com a API Gemini / AI Studio enviando `functionDeclarations`.
   - `buildOpenCodeModelTurn({ base, model, systemPrompt, effort })`: Constrói o invocador compatível com o OpenCode local.
   - `parseStructuredToolCallsFallback(text)`: Extrai chamadas de ferramenta mesmo se o modelo cuspir em JSON/XML no meio do texto.
2. Criar `tests/atelier-engine-adapters.test.js` cobrindo:
   - Formatação correta dos payloads de envio para Gemini e OpenCode.
   - Parser de respostas com chamadas de ferramentas e texto.
   - Recuperação e fallback resiliente em textos mistos.

## Critérios de Aceite
- [x] Adaptador Gemini monta payload válido para `generateContent` com `functionDeclarations`.
- [x] Adaptador OpenCode monta payload compatível com a API local (`formatOpenCodeMessages`).
- [x] Fallback extrai chamadas de ferramenta de saídas textuais com segurança (`parseStructuredToolCallsFallback`).
- [x] Código respeita o limite de 300 linhas por arquivo (210 linhas).
- [x] 100% dos testes passam em `node --test tests/atelier-engine-adapters.test.js`.

## Evidências de Conclusão
- Criado `ui/server/services/atelier-engine-adapters.service.js` (210 linhas) contendo:
  - `formatGeminiContents`: Mapeamento de turnos `user` (incluindo `functionResponse`) e `model` (com `functionCall`).
  - `formatOpenCodeMessages`: Formato compatível com OpenAI/OpenCode com `tool_calls` e `tool_call_id`.
  - `parseGeminiCandidate`: Extração limpa de function calls descartando thoughts internos.
  - `parseStructuredToolCallsFallback`: Extração resiliente de blocos `<ferramenta nome="...">` / `<tool name="...">` caso o modelo emita texto com JSON embutido.
  - `buildGeminiModelTurn`: Invocador assíncrono para o Gemini com injeção de schemas de ferramentas e tratamento de erros.
- Criado `tests/atelier-engine-adapters.test.js` com 5/5 testes automatizados aprovados.
