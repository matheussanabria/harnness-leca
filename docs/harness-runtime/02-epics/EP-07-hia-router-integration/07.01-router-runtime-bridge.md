# 1. Identificação
- **História:** 07.01 — Ponte entre HIA Router e Local Runtime para Roteamento Local-First
- **Arquivo Alvo:** `tools/lib/hia/router.js`

# 2. Contexto
O roteador HIA já possuía uma camada Local-First restrita a poucas intenções curtas. A Fase 2 precisa ampliar essa camada para as intenções de extração de artefatos e entidades, que são rotineiras e consumem cota desnecessariamente.

# 3. Objetivo
Reconhecer prompts de extração como candidatos locais, verificar a viabilidade de hardware e devolver uma decisão de roteamento para `ollama:qwen3.5:4b` quando a máquina comporta a inferência.

# 4. Requisitos
- **RF-01:** Reconhecer intenções `extrair artefatos`, `extrair entidades`, `extraia o json`, `classifique`, `resuma em poucas palavras` e `gere um teste simples`.
- **RF-02:** O tamanho do prompt é limitado a 2500 caracteres para preservar o orçamento de contexto do modelo local.
- **RF-03:** A delegação só ocorre quando `getHardwareSnapshot().viable` for verdadeiro.
- **RF-04:** A decisão devolve `destination: "local_llm"`, `targetId: "ollama:qwen3.5:4b"`, razão explicativa e `estimatedTokensSaved`.
- **RF-05:** Nenhuma chamada a motor em nuvem é disparada como fallback (ADR-005).

# 5. Arquitetura
Camada 2 do roteador: detecção por intenção + verificação de hardware. A execução é feita pelo runtime local; o roteador apenas decide.

# 6. Implementação Passo a Passo
1. Ampliar a expressão regular de intenções locais.
2. Elevar o limite de tamanho do prompt de 1500 para 2500 caracteres.
3. Substituir o alvo `qwen2.5-coder:1.5b` por `qwen3.5:4b`, coerente com o modelo usado na extração.
4. Manter a razão com menção à preservação de cota de IA.

# 7. Testes Pré-definidos
- Prompt de extração resulta em `destination === "local_llm"` e `targetId === "ollama:qwen3.5:4b"`.
- A razão contém a indicação de preservação de cota.

# 8. Critérios de Aceite
- [x] Intenções de extração são delegadas ao runtime local.
- [x] Hardware inviável mantém o fluxo original.
- [x] Nenhum fallback para nuvem.

# 9. Riscos
- `qwen3.5:4b` exige mais RAM que o modelo anterior; a checagem de viabilidade protege o caso comum, mas o modelo precisa estar instalado localmente.
