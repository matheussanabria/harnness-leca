# 1. Identificação
- **História:** 02.02 — Serviço de Classificação de Tarefas
- **Arquivo Alvo:** `tools/lib/runtime/classifier.js`

# 2. Contexto
Com o cliente Ollama estruturado e o validador de schema implementados, precisamos do serviço orquestrador de classificação que monta o prompt de poucas instruções, aciona o modelo local e aplica a validação.

# 3. Objetivo
Implementar `classifyTask({ text, model, signal })` retornando a classificação validada e as métricas de inferência, com fallback controlado caso o modelo local falhe.

# 4. Requisitos
- **RF-01:** Utilizar prompt otimizado de extração com exemplos few-shot compactos.
- **RF-02:** Acionar `generateStructured` do `ollama-client.js`.
- **RF-03:** Validar saída via `validateClassification`.
- **RF-04:** Garantir que o resultado contenha aviso explícito de que não há execução automática associada.

# 5. Arquitetura
Serviço isolado em `tools/lib/runtime/classifier.js` com menos de 200 linhas.

# 6. Implementação Passo a Passo
1. Construir prompt de sistema focado no vocabulário fechado.
2. Invocar o cliente local Ollama com modelo padrão (`qwen3.5:4b` ou `qwen2.5-coder:1.5b`).
3. Validar a saída JSON e montar retorno com métricas.

# 7. Testes Pré-definidos
- Classificação de prompt de bug, feature e refactor.
- Teste de comportamento quando Ollama retorna JSON com erro de schema.

# 8. Critérios de Aceite
- [ ] Retorna objeto de classificação estrito.
- [ ] Tempo de resposta compatível com execução local.
- [ ] Ausência de efeitos colaterais de execução.

# 9. Riscos
- Alucinações de schema: mitigado por validação estrita que rejeita respostas malformadas.
