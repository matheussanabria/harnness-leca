# 1. Identificação
- **História:** 01.01 — Cliente HTTP e Configuração Base do Ollama Adapter
- **Arquivo Alvo:** `tools/lib/runtime/ollama-client.js`

# 2. Contexto
O Ollama roda localmente em `http://localhost:11434`. Precisamos de um cliente HTTP desacoplado com tratamento de URL configurável (`OLLAMA_URL`), restrição a endereços locais e timeouts seguros.

# 3. Objetivo
Implementar a fundação do cliente HTTP do Ollama em `tools/lib/runtime/ollama-client.js` com menos de 200 linhas, suportando `AbortSignal` e headers padronizados.

# 4. Requisitos
- **RF-01:** Conectar a `http://localhost:11434` (ou variável `OLLAMA_URL`).
- **RF-02:** Validar que a URL de destino é estritamente local (`localhost` ou `127.0.0.1`).
- **RNF-01:** Tamanho máximo de 200 linhas no arquivo.
- **RNF-02:** Timeout padrão de 1500ms para ping e configurável para inferência.

# 5. Arquitetura
O módulo exportará funções utilitárias: `getBaseUrl()`, `isLocalUrl(url)` e métodos wrapper de fetch resiliente.

# 6. Implementação Passo a Passo
1. Criar `tools/lib/runtime/ollama-client.js`.
2. Implementar validação de URL local com regex de segurança.
3. Configurar injeção de parâmetros padrão (`keep_alive`, `num_predict`, `temperature`).

# 7. Testes Pré-definidos
- Testar chamada com URL válida e URL remota bloqueada.
- Testar timeout automático via `AbortSignal`.

# 8. Critérios de Aceite
- [ ] Conexão HTTP funcional com o daemon local.
- [ ] Endereços externos rejeitados por segurança.
- [ ] Código modular com menos de 200 linhas.

# 9. Riscos
- Daemon não inicializado no sistema: deve retornar erro limpo sem crash.
