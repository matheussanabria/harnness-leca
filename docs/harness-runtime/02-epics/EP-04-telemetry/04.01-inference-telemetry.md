# 1. Identificação
- **História:** 04.01 — Registro Estruturado de Métricas de Inferência
- **Arquivo Alvo:** `tools/lib/runtime/telemetry.js`

# 2. Contexto
Precisamos auditar o desempenho de cada chamada de classificação (tempos de prompt, geração, carga e contagem de tokens) para alimentar comparações com os benchmarks locais sem expor dados confidenciais do usuário.

# 3. Objetivo
Implementar `tools/lib/runtime/telemetry.js` com a função `recordInference(entry)` gravando em `logs/telemetry/runtime-shadow.jsonl`.

# 4. Requisitos
- **RF-01:** Gravar `correlationId`, `model`, `tipo`, `complexidade`, `executorSugerido`, `tokensPrompt`, `tokensGenerated`, `totalDurationMs`, `loadDurationMs`, `promptDurationMs`, `evalDurationMs`, `valid`, `error`.
- **RF-02:** **Sanitização estrita:** Não persistir texto completo do prompt nem respostas livres ou tokens de autorização.
- **RF-03:** Formato append-only JSON Lines.
- **RNF-01:** Código com menos de 150 linhas.

# 5. Arquitetura
Gravador de eventos com criação automática de diretório e rotação simples.

# 6. Implementação Passo a Passo
1. Criar `tools/lib/runtime/telemetry.js`.
2. Implementar sanitização dos campos antes da serialização.
3. Gravar em arquivo `logs/telemetry/runtime-shadow.jsonl`.

# 7. Testes Pré-definidos
- Validar criação do arquivo de log.
- Validar ausência do texto do prompt no payload gravado.

# 8. Critérios de Aceite
- [ ] Registros JSONL consistentes e sanitizados.
- [ ] Sem vazamento de dados sensíveis.

# 9. Riscos
- I/O concorrente: append em arquivo único tratado por chamadas síncronas rápidas do Node.js.
