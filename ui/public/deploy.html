💡 Como pegar o Webhook de Deploy no Easypanel (Hostinger VPS)
▼ Expandir

O Easypanel permite disparar o rebuild e deploy do seu container automaticamente através de uma requisição HTTP:

  1. Acesse o painel do Easypanel na sua VPS (ex: https://painel.seudominio.com).
  2. Entre no Projeto e selecione o Serviço desejado (ex: o backend ou frontend).
  3. Vá na aba Settings (ou Source dependendo da versão) e localize a seção Deploy Webhook.
  4. Copie a URL gerada (ela contém o token de autenticação único).
  5. Clique no botão ⚙️ Configurar do card correspondente abaixo e cole a URL no campo de Webhook. Pronto!
💡 Dica de Segurança: As URLs dos seus webhooks são salvas no arquivo local global/deployments.json (que está no seu .gitignore) e nunca sobem para o GitHub.
