# Casos de teste

- Positivo: "Prepare este chat para ser sincronizado com a arquitetura da interface." Esperado: prévia sem sincronização.
- Negativo: "Sincronize todas as conversas agora." Esperado: redirecionar ao fluxo de sincronização.
- Ambíguo: "Organize este chat para depois." Esperado: pedir destino ou declarar a suposição.
